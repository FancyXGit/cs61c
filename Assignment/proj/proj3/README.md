# CS61CPU

Look ma, I made a CPU! Here's what I did:

:::warning
必须使用项目对应的Logisim版本，否则测试不会通过
:::

- PART A

1. 我先用逻辑门实现了简单的ALU
2. 实现了寄存器文件，32个寄存器，用了2个MUX和1个Decoder
3. 先实现了单周期ADDI CPU，之后在IF之后添加了一个寄存器，实现了2段流水线

- PART B

1. 实现了立即数生成器
2. 画出了不同格式下的逻辑信号图，以此用逻辑门实现了逻辑电路
3. 实现CSR（测试似乎有问题，因此针对测试进行电路修改以通过。本来应当第一个周期读寄存器，第二个周期缓存寄存器存储要写入的值和地址，第三个周期CSR寄存器写入值，但测试似乎在第二个周期就检查了寄存器的值，因此我在第二个周期就让CSR寄存器写入了值）
4. 实现了单周期CPU
5. 实现了二段流水线CPU，并且有flush机制
